== Converting a 2.0 System [[convert-20]]

This chapter upgrades an Image BBS 2.0 system to 3.0, from start to finish.
Read <<setting-up>> up to <<install-methods>> first: it explains the six Image drives and what goes on each.

NOTE: This is the recommended way of converting 2.0 to 3.0.
Other ways may work but have not been tested.
Since you are already running Image 2.0, keep the same Image drive assignments for the 3.0 upgrade.

****
The file `im` line `3074` is preconfigured to run from drive 0.
This is the default partition on most drives.

NOTE: If running on a Lt. Kernal and your boot LU is not LU0, change the `0` in line `3074` to the number of your boot LU.
****

. Make a complete backup of all your Image 2.0 drives.
. Copy `bd.data` from your programs drive to your Etcetera Disk.
. Move your 2.0 boot and program files off your Program Disk, to another disk or partition: don't scratch them.
You'll want them if you go back to 2.0, and they include any modules you've written or installed.
. Copy all the files from IMAGE 3.0 D1 to your Program Disk.
. Copy `bd.data` from the Etcetera Disk to the Program Disk, but rename it to `d.data`.
. Copy `e.lightdefs`, `e.lightbar` and `e.ecs.main` from IMAGE 3.0 D2 to your Etcetera Disk, replacing the existing files.
. Copy the Image 2.0 `s.*` files you've customized (your login and welcome screens, board entry screens, and so on) to another disk or partition, to put back afterwards.
. Copy all the `s.*` files from `IMAGE 3.0 D2` to your System Disk, replacing the 2.0 files of the same name.
Your other 2.0 `s.` files are left as they are.
. Copy back the customized screens you set aside in step 7, if you want to keep them.
3.0's menus (`s.menu` _n_) and its `s.m.*` files list 3.0's commands and options, so keep 3.0's versions of those.

NOTE: Disk 2's ``+s.*+`` files are the menus (``s.menu`` _n_), the login, welcome, start and end screens (``s.login``, ``s.welcome``, ``s.start``, ``s.end``), the screens for entering each section (``s.SB``, ``s.UD``, ``s.UX``, ``s.EM``, ``s.GF``, ``s.Sig``, ``s.VF`` ...), and the setup files (``+s.m.*+``).

****
If you want to run the "`Today in History`" login module in 3.0, copy all the `today.*` files from IMAGE 3.0 D2 to your Etcetera Disk.
****

=== Run the Conversion

include::includes/boot-command.adoc[]

. When prompted, type kbd:[3] `Convert a 2.0 system`.

. Image 3.0 will perform all the necessary tasks of converting your 2.0 to 3.0 and will end up at the idle screen.

====
NOTE: Since the 3.0 modem configuration is different from 2.0, Image BBS won`'t communicate with your virtual modem yet.
You can fix this in a later step.
====

[start=6]
. Log on to your BBS from the console.
. Type kbd:[IM] to go to the Configuration Editor.

=== Configure the BBS in `IM`

The Configuration Editor's options are described in <<im-configuration>>.

[start=8]
. Configure your modem: kbd:[J] `Modem Config`, then kbd:[B] `Setup/Import Modem Config` and kbd:[1] `Setup New Modem Config` (see <<gglabs-example>> and <<im-modem>>).
When finished, select kbd:[X] `Exit Modem Config`, and answer `Update Modem Flags?` with kbd:[Y]es.
. Configure anything not already configured in kbd:[I] `Misc. Features` (see <<im-misc>>).
. Go into kbd:[D] `Logon Editor` and configure your kbd:[A] `Login Mods` (login modules).
Its kbd:[H]elp explains how (see <<im-login-mods>>).
. Configure your new kbd:[B] `Maint Mods` (nightly AutoMaintenance modules; see <<im-maint-mods>>).
. Configure your kbd:[H] `Lightbar/Alarms`, kbd:[A] `LightBar Defs` (the lightbar's defaults at boot; see <<lightbar-defaults>>).
. Select kbd:[N] `Base Editors`.
This is the menu that 2.0's kbd:[SM] command used to show, if you've installed it from the SM disk (see <<im-base-editors>>).
You shouldn't have to do anything there, but you can look around if you want to.
. Select kbd:[K] `Quit` to go back to the Configuration Editor, then kbd:[Q] `Quit` to go back to the Main Prompt.

=== News and General Files

[start=15]
. Type kbd:[NF] to go to the News files, and edit, add or configure any that need it (`n.$Welcome!`, perhaps).
kbd:[Q]uit back to the Main Prompt when done.
. Type kbd:[GF] to go to the General Files section (see <<general-files>>).
Nothing is configured there yet: 2.0's General Files don't carry over, because 3.0's files are in a different format, so set your libraries up again.

From here, see <<final-notes>>.
