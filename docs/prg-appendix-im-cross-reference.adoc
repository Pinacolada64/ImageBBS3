== Image 1.x to 3.0 `im` Line Cross-Reference [[appendix-im-cross-reference]]

Image 1.2 and 1.3 numbered the `im` routines from 1000 up; 3.0 numbers them from 1 to 999, and moved many of them into `sub.` modules.
To convert a 1._x_ module, change each jump to a 1._x_ `im` line to its 3.0 equivalent below (see <<conversion-and-backward-compatibility>>).

The table is worked out from `im.emul13`, the 1.3 emulation layer: most of its lines at 1000-1999 just `goto` the 3.0 line, or set `im` and go to a `sub.` module.
Where the release modules make the same call, they use the 3.0 form shown (`i.ED`, for example: `im=7:gosub 445`).

TIP: Jumps to lines from 3000 on are the module's own lines, and need no change.

=== Notes on `im.emul13` [[im-emul13-notes]]

The sub-module calls above are how 3.0 _should_ answer them.
In the 12/31/2023 release, `im.emul13` itself gets several of them wrong, so a 1._x_ module run through it misbehaves.
`core/im.emul13.lbl` has these fixed (10/14/2026), except for the modules 3.0 doesn't have:

* Its jumps into `sub.misc`, `sub.editor`, `sub.feedback`, `sub.display` and `sub.info` (lines 2400, 2402, 2422, 2426 and 2428) go to `im` lines 45, 40, 44, 43 and 47.
In the release `im`, those modules load from lines 445, 440, 444, 443 and 447; 40 to 47 show `s.new user`, `s.config` and `e.say` sayings.
* Its calls to `sub.misc2`, `sub.local`, `sub.param1`, `sub.comm1`, `sub.comm2`, `sub.stats`, `sub.bar` and `sub.menus` (and to `nodes`, `screens` and `trans`, which 3.0 doesn't have) go to line 2500, which prints "`System Sub-Routine File Error!`".
* 1450 (Disk Command) goes to line 360, which isn't in the release `im`.
