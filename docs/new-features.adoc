== New Features [[new-features]]

This chapter describes features that are new in Image BBS 3.0, in more detail than the list in "`What`'s New`".

=== Programmable Function Keys [[function-keys]]

The sysop can give each of eight function keys a line of text, up to 75 characters, which the BBS types when you press the key with kbd:[Ctrl] or kbd:[C=] at the console.
Use them for things you type often: a command you use a lot, a stock reply, a long handle.

The C64 has four function keys: kbd:[Ctrl] with one gives the odd-numbered key, kbd:[C=] the even-numbered one.

| kbd:[Ctrl+f7] | F7 | | kbd:[C=+f7] | F8

They work wherever the BBS is reading the C64's keyboard: at a prompt, in the text editor, and so on.
They're for the sysop at the console: a caller's function keys don't use them.

A key's text can end by pressing kbd:[Return], so the key both types a command and enters it.

To set the keys, use the Function Key Editor in `IM` (see <<im-function-keys>>).
They're kept in `e.fkeys` on the Etcetera drive, and the BBS loads them when it starts ("`Enabling Function Keys...`").

NOTE: Before October 2026, pressing kbd:[Ctrl] or kbd:[C=] with a function key could lock up the BBS.
The ML read the key's text from the wrong address, and could copy hundreds of bytes over the C64's system vectors.
