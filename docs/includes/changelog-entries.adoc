=== 2026-10-13

* `&,25` Sound: _repeat_ `0` plays the sound once (it doesn't stop it); `&,25,255` stops a repeating sound; a repeating sound ignores other `&,25` calls; sound `0` follows the lightbar's Local Beeps Disable. `i.test calls` has a demo.
* Version 3.1: the boot files are now `boot 3.1`, `image 3.1` and `ml 3.1`.
* `&,5` Get Version: the ML returns version 3.1 in `lp` and revision 0 in `a%` (it returned 2.0, and never set `a%`); `a$` is the 8-character git commit the ML was built from.
* `im` routines: lines 40 and 41 display `s.new user` and `s.config`; how lines 70-79 load modules (only if not already in memory, the `sub.*` module stack); new rows for lines 77, 78 and 80; anchors for the lines from 30 to 80.
* Variables: the Image 1.2 Arrays table had one column (its `cols` setting wasn't quoted); it has Variable and Purpose again.
* A table that fits on one page is no longer split across two in the PDF (14 were, some leaving just a heading and a row at the bottom of a page); longer tables still start where they are.
* `&,1` Input Line: the editor flags for bits 0, 3 and 7 were backwards (they allow graphics and the MCI character, and make Delete on column one exit); the password flags are confirmed, with examples; `i.test calls` tests password input and any editor flags.
* `&,1` now clears its password flags when input ends (`source/swap1.s`); after `&,1,x,1`, all output was masked until the next `&,1`.
* Word-wrap: `&` with `lp=1` ends the line itself and resets `lp`.
* The password mask character is at 4850 (`$12f2`), not 17138; `&,6` sets an input length of 15, not 14.

=== 2026-10-12

* New appendix: Test Programs: what each `i.test` program tries, and how to run them from the `i.tests` menu.
* New appendix: this changelog.
* `++ copier`: new section.
The four calls (copy all, count bytes, copy some, protocol number), and the new `&,16,3`, which compares two files.
How count and copy some pack a file behind its length and unpack it.
The protocol screen's counters.
Closing a drive's command channel closes every file it has open.
* `++ menu2` (cursor menus): its parameters worked out, and what it doesn't check (empty hotkeys, short `types$`, long titles).
The menu item record, adding items one at a time or from a struct array, drawing a menu and choosing from it.
* `&,9`: number variables are now shown as digits (they showed garbage).
Variable 31 is `b%`, not `b$`.
* Memory map: `$1764` is used by `i.tests`.
* `i.test-convert` is now `i.test convert`.
* BASIC listings are syntax-highlighted again (the setting was outside the document header), with a new lexer for Image BBS BASIC that knows `&` calls, `$hex` numbers and C64List's tokens.
* In code listings, control codes inside strings (`{f6}`, `{white}`, `{clear}`...) are shown in reverse field, as in quote mode.
* Code examples use C64List's `{f6}`, `{f3}` and `{pound}`, not `kbd:[...]` (which only works in running text); the `&` date example shows kbd:[Ctrl+D].
* Apostrophes in code (`O\'MALLEY\'S BAR`, `?redim\'d array`) showed as boxes: they were turned into typographic quotes the code font doesn't have.
* Mentions of `&` calls link to the call's section and give its name (53 more), and `&,1`, `&,9` and `&,22` have their own anchors.
* The Jump Tables appendix has a heading at last, and the Protocols section (the ML modules: `{plus}{plus} copier`, `{plus}{plus} index`, `{plus}{plus} punter`, `{plus}{plus} reader`, `{plus}{plus} menu2`) has moved into it, as "`Jump Tables and Protocols`".
* Lightbar Reference, Memory Map and File Formats are now appendices (A, B and D), with Jump Tables and Protocols (C).
* Formatting fixes: stray backticks where code touched italics or an apostrophe, and in the `an$` copy example of `&,64`.
* How to Use This Guide: what the curly-brace tokens in listings mean, and what to type for them.
* `im` routines table: narrower line-number columns, so the Purpose column is wider.
* Table headings, and short values like `$42f2`, no longer wrap in the PDF (28 tables had a heading that did, some mid-word, like "`Function`").
